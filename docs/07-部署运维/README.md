## 部署前必读：三个最容易踩的坑

### 1. 不给 `--policy` 则 rtdbd 拒绝所有写

`irt_policy_allows()` 末尾是 `return 0; /* deny by default */`。未指定 `--policy` 时策略为空（规则数 0），循环不执行，直接落到 deny 分支。

**表现：rtdbd 正常启动、健康检查通过，但所有写请求返回拒绝。** 且不会自报错误。这是设计上的 fail-closed，部署时必须提供 `--policy`。

### 2. `peek()` 是单拷贝，不是零拷贝

`indurtdb_peek()` 把数据拷到**线程本地缓冲**，**同线程下次 peek 即覆盖**。需要长期持有请用 `indurtdb_read_point()`。详见 `CODEBUDDY.md` 与 `05-SDK手册`。

### 3. 写冲突返回 `-2`（busy）且不自动重试

`write_*` 遇到 Seqlock 写中直接返回 `-2`。**调用方必须自行实现重试循环**，否则高并发下会丢写。

## 平台支持

| 平台 | 状态 |
|---|---|
| **Linux（x86_64 / aarch64 glibc）** | ✅ 唯一经过验证的平台，本文全部内容适用 |
| SylixOS / ARM RTOS | ⚠️ OSAL 为 POSIX 薄封装，**从未在目标板验证**，不支持生产部署 |
| 其他 | CMake 直接 `FATAL_ERROR` |

> 详见 [`06-开发规划/08-功能评审与下一步规划.md`](../06-开发规划/08-功能评审与下一步规划.md) §11 第 1 项：SylixOS 移植已暂缓，按技术债管理。

## 系统要求

| 项 | 要求 |
|---|---|
| 编译器 | GCC / Clang，C11 + C++17（仅测试用） |
| 构建 | CMake ≥ 3.15 |
| 测试依赖 | GTest（`find_package(GTest REQUIRED)`） |
| 运行时 | glibc；`pthread`、`rt` |
| 权限 | 读写 `/dev/shm`；启用鉴权需 `SO_PEERCRED`（Linux 特有） |
