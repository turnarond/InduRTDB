## 第 1 节：范围与可达字段矩阵

S5b 定位：补强 S5 取证工具使其能取 B 段字段真值（body 捕获 + 负例 + 两态比对），**P10/P11 等硬不可得字段仍 pending、发布门不全绿**。工具 JSON 可变、B 段台账 JSON 结构不变。

字段可达矩阵（调研结论）：

| 类别 | 字段 | 处置 |
|---|---|---|
| 可真取（body 捕获后） | P7 `deny_bad_token`/`admin_set_peers_ok`；P8 `set_peers_idempotent`/`reject_invalid`/`reject_over_limit`/`old_table_unchanged`/`reject_self`（需 self_addr argv）；S4 `notify_latency_ns`；F4 `epoch_before/after`/`digest_match_proc`/`peers_restored`；现有可达性字段 | on-site，可回填 |
| 条件可真取（全授权含） | `deny_peer_write`（sync_peer client + 成员预置或非成员 hello DENIED 替代）、`peer_notify_leak`（sync_peer client + datagram 负向窗 + 正向写触发）、`proc_restart_no_fullsync` 辅助 | on-site（条件成立时） |
| 仍不可得 | P7 `deny_non_loopback`（server 仅绑 loopback，分支不可达）、P8 `join_triggers_full`、P9 `rbe_gate_hits/misses`/`snapshot_done_caps_only`、P10 全场、P11 `machine_restart_pull_full`、F4 `subs_restored`、F3a 两字段、P3/P6 其余 | unavailable + 精确 reason，pending |

## 第 2 节：工具改造形态

**A. body 捕获**（核心）：`on_rpc` 回调内 `memcpy` payload→自有缓冲（SDK `vsoa_client.h:98-100` 规定回调返回即失效，回调内 memcpy 是唯一正确范式；当前 s5_forensics.c:80-83 "无 body 捕获"是实现简化非 SDK 限制）；`call_rpc` 返回 `status+body_len+body[]`。

**B. 四类 client**（argv 运行时传 token/service_id，不写真值）：
- PLC client：`/stats/notify`（body→notify_latency_ns）、`/point/write`（正向写 1 点触发 NOTIFY，供 peer_notify_leak 负向窗）、错 token hello（deny_bad_token）。
- sync_admin client（loopback）：`/sync/peers/{set,get}`（幂等 set：当前表原样 set + get 回读；四类拒绝负例 + 旧表不变比对）。
- sync_peer client：hello + 订阅 + datagram 负向窗（peer_notify_leak）；`/point/write` 应 DENIED（deny_peer_write）；127.0.0.1 临时成员预置后恢复。
- bad-token client：独立 client 用错 token hello（deny_bad_token）。

**C. 三模式采集**：
- f2：P7 大部 + P8 大部 + S4 延迟真值 + 可达性。
- f3a：仍只可达性 + 两字段 unavailable（无注入工具，裁决不变）。
- f4：before 态写状态文件（epoch/digest/peers/点值摘要）→ 重启后 after 态读回比对（epoch_before/after、digest_match_proc、peers_restored）；`subs_restored` unavailable。digest 用 S1 纯函数独立重算（链 rtdbd_digest.c）。

**D. 不可得字段理由精确**：`deny_non_loopback`（server 仅绑 loopback）、`join_triggers_full`、`rbe_gate_hits/misses`、`snapshot_done_caps_only`、P10 三字段、`machine_restart_pull_full`、`subs_restored`、F3a 两字段、P3/P6 其余。

**E. 工具 JSON 可变**：`VALUE_LEN` 扩到承载 peers 摘要；B 段台账 JSON 结构不动。
