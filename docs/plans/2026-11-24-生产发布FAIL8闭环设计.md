> 关键前提澄清：① 用户确认具备 F2(6节点)/F3a(网络注入)/F4(整机重启)现场条件；② 9 个未注册 IR/Gate 真实现（非补名字），F3a/F4 取证工具尚不存在需建；③ 取证分工 = **我建工具 + 用户现场执行 + 我核验**；④ 独立复核人 = **用户指定的独立工程师**（执行者不自签，具体姓名现场取证时提供）；⑤ tag/合 main 由用户最终确认，不预先授权、不擅自执行。

## 0 立场（不可动摇）

- **不手填假绿**：`release_gate.py` 的 `ir_snapshot` 当前是纯文本子串匹配（写名字即过 = 假绿，q2 变更卡已登记风险）——必须改为**真实 ctest 注册比对**；B 段 7 项须真值 + 真实 evidence/verified_by/verified_at，不填伪值。
- **任一阶段失败即停**，不跳过、不伪造；现场数据取不到如实停在"待取证"。
- **责任边界**：我核验"证据数值 ↔ 台账字段 ↔ 判据"一致性；现场操作真实性由执行者签署、独立工程师复核；我作为实施者不自签 `verified_by`。
- **产品边界不变**：主备自动同步/集群跨节点同步不做（node-server 提供）——生产发布不改此边界。

## 1 调研事实（当前状态）

- **FAIL 8 构成**：`check_release_conditions.py --json` ok=false，7 条 FAIL = P3/P6/P7/P8/P9/P10/P11 全 `pending` + `fields:{}` + 空证据（`docs/08-验证记录/v3.12-B段数字落库.json:4-13`）；第 8 条来自 `release_gate.py:137-155` 的 ir_snapshot。
- **13 个 required_irs**（`docs/03-设计文档/reviews/v3.12-条件闭环台账.json:47-61`）：IR1_FullSnapshot、IR2_AuthDeny、IR3_DeferredQueue、IR4_PeersRuntime、IR5_NotifyDirection、IR6_RestartSemantics、IR7_PartitionConverge、Gate_T1_SyncOverhead、Gate_T2_LocalP99、Gate_T3_WallClock、Gate_T3_RSS、IR4_NetworkPartition、IR5_StaleEpoch。OFF 快照注册 3（IR2/IR3/IR4）、ON 注册 4（+IR5_NotifyDirection）；**缺 9 名均无同名 cpp/ctest 实现**。
- **现场工具现状**：`vsoa_cluster_harness.cpp:104-280` 有 Linux loopback fork/SIGKILL/SIGSTOP 骨架，但 1/6/30s 断网注入、整机重启两态均需演进；SylixOS 无 fork、板上不能直接用；`scripts/` 无 F2/F3a/F4 编排脚本。
- **发布前置**：四处统一 3.11.0（`VERSION`/`CMakeLists.txt`/`indurtdb.h`/`CHANGELOG.md`）；对外"未验证/不支持生产部署"散见交付说明/部署运维/README/docs README，无机械门禁锁定；无 release artifact（marker/md5）；main 与 release 分支不同 SHA，tag 最新 v3.11.0。

## 2 阶段一：建能力（Linux 可验证，我实施）

1. **9 个 IR/Gate 真测试**（新增真实 ctest，非改名）：
   - 快照/重启：`IR1_FullSnapshot`（全量快照写→读逐字节一致）、`IR6_RestartSemantics`（kill/重启后 epoch 单调 + 订阅/peers 恢复）、`IR7_PartitionConverge`（分区隔离+收敛）。
