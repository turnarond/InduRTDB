# 验证记录

本目录存放**验收证据**：端到端测试输出摘要、运行日志片段、协议/布局实测记录，
以及功能视图的**浏览器截图**。证据用于佐证「红表用例 → 绿」的验收结论，不替代代码与设计文档。

## 命名约定

- 截图：`v<版本>-T<任务号>-<简述>.png`，例如 `v3.9-T7-分区视图.png`。
- 文本记录（可选）：`v<版本>-T<任务号>-<简述>.md`。
- 文件名统一使用小写 ASCII 与连字符，不含空格。

## 约定

- **不得伪造证据**：截图须为真实运行的界面，测试输出须可复现（附运行命令）。
- 截图由任务编排者或其指派的浏览器验证环节采集；代码任务本身不产出图片。
- 记录与设计文档 `03-设计文档/`、任务规划 `06-开发规划/` 互补：设计说「怎么设计」，
  记录说「实测结果如何」。
