> 生成日期：2026-11-11 ｜ 分支：`feature/v3.12-m34-ir`（未合 main / 未 push）

## 1. 实施范围

切片 3 解锁 **IR6 `proc_restart_no_fullsync` 子判据**（boot_id 变化即「非首次」启动）。计划原设想「`rtdbd.c` 启动生成 boot_id + `rtdbd_peer_table.{h,c}` 同步时写 boot_id/计算 lag」。落地时根据实际分层调整：

- `boot_id`：**进程级单例**生成 + 存取落 `rtdbd_peers_global.{h,c}`（与成员表单例同模块），`rtdbd.c:main` 启动时调用 `rtdbd_peers_set_boot_id(rtdbd_boot_id_generate())`。
- `lag`：精确语义（degraded 等）**§8.3-6 协议注释明确「留字段，不在本协议裁决」**。故本切片仅落地**最小可观测差值** `lag = local_offset − peer.applied_offset`（饱和 0），抽为纯函数 `rtdbd_peer_lag()`（`rtdbd_peer_table.h` inline），由 `rtdbd_peers_apply.c`（SET_PEERS 包装）调用写入 `peer.lag`；`boot_id` 透传（来自上报节点）。
- `local_offset`：`rtdbd_peers_global` 提供存取器，**默认 0**；由同步流应用 delta 时推进（留后续切片/IR6），本切片仅落地计算逻辑 + 存取器。

## 2. 改动文件

- `rtdbd/src/cluster/rtdbd_peer_table.h`
  - 新增 `static inline uint32_t rtdbd_peer_lag(uint64_t local, uint64_t applied)`（最小 lag 差值，饱和 0；供 apply.c 与单测共用，避免依赖全局状态）
- `rtdbd/src/cluster/rtdbd_peers_global.{h,c}`
  - 新增 `rtdbd_boot_id()` / `rtdbd_peers_set_boot_id()` / `rtdbd_boot_id_generate()`（CLOCK_MONOTONIC 纳秒高位 + 随机低位，每次启动高概率不同）
  - 新增 `rtdbd_peers_local_offset()` / `rtdbd_peers_set_local_offset()`
- `rtdbd/src/cluster/rtdbd_peers_apply.c`
  - `rtdbd_peers_apply_set` 在 SET_PEERS 时对每个 peer 计算 `buf[i].lag = rtdbd_peer_lag(local, applied)`（覆盖旧透传，lag 改为本节点视角滞后量）
- `rtdbd/src/rtdbd.c`
  - `main` 启动：`rtdbd_peers_set_boot_id(rtdbd_boot_id_generate());`
- `tests/integration/IR4_PeersRuntime.cpp`
  - 新增 `LagComputedAsLocalMinusApplied`（纯函数：150-100=50、不落后=0、恰好追上=0、local0=0）
  - 新增 `BootIdGeneratedNonZero`、`BootIdRoundtrip`
- `tests/integration/CMakeLists.txt`
  - IR4 链接追加 `rtdbd_peers_global.c`（boot_id 测试用）
