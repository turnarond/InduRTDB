## 设计决策

> v2 返工：fix 首轮 2 P0+5 P1；用户裁决 epoch=全局单调、digest=点快照输入。

1. **全局 epoch 模块**（`rtdbd/src/cluster/rtdbd_epoch.c/.h`，fix P0-1）：
   - `rtdbd_epoch_t` 进程级单例（全局单调、非零），API：`rtdbd_epoch_next()`（分配下一个 epoch）、`rtdbd_epoch_current()`、`rtdbd_epoch_is_stale(uint64_t frame_epoch)`（`frame_epoch < current` 即陈旧）、`rtdbd_epoch_key(uint64_t epoch, uint64_t boot_id, const char* node_id, rtdbd_epoch_key_t* out)`（组成 `(epoch,node_id)` 字典序裁决键，boot_id 作次级 tie-break）。
   - 不复用 `rtdbd_session_t.epoch`（会话级、reset 归零，仅保留为会话展示字段，**不参与同步裁决**）；13 号 §8.3-1"服务端分配"在本模块完成。
   - 重启单调性：epoch 与 boot_id 绑定（boot_id 非持久化、高概率不同，24 号:37/87），本卡只保证**进程内单调**，跨重启单调由 S2 `/sync/hello` 交换时取 max 推进（本卡提供 `rtdbd_epoch_advance_to()` 原语）。
2. **digest 纯函数**（`rtdbd/src/cluster/rtdbd_digest.c/.h`，fix P0-2/P1-1/2/3）：
   - 输入 `const indurtdb_point_t* points, uint32_t count`（点快照数组，由调用方按 id 枚举 `indurtdb_h_peek(id)` 填充；不碰 `indurtdb_t` 内部、不改 lib API/ABI）。
   - 新写 **FNV-1a-64 字节累积**（不复用 `irt_hash_fnv1a32`——其只吃 NUL 字符串、32 位；P1-1）：结构段按 `(id,partition,name[64],type,access)` 累积，值段按 `(id, type, 有效字节(value), quality, source_timestamp_ns)` 累积——**按 type 定有效字节**（bool 1/int32 4/int64 8/uint32 4/float 4(IEEE754 原始字节)/double 8(原始字节)/string 32 全字节固定），避免 union 尾部未初始化污染（P1-2）。字段名用真实的 `source_timestamp_ns`/`value`（P1-3），id 是遍历 key 非结构字段。
   - 输出 `rtdbd_digest_t{ uint64_t struct_hash; uint64_t value_digest; uint32_t n_points; char hex[64]; }`：`hex` 格式 `fnv1a64-v1:<struct_hash:016x>:<value_digest:016x>:<n_points>`（算法版本标记，P2-1；映射 P10 `terminal_hash` 与 P11 `digest_match` 的比对载体，node_id 绑定留给 S2/S3）。
   - `rtdbd_digest_equal()` 逐字段比较（32/64 位精确，非字符串前缀）。
3. **测试**（OFF 纯逻辑、unit GLOB 自动注册，fix P1-4）：
   - `tests/unit/test_c_digest.cpp`（`file(GLOB "test_c_*.cpp")` 自动注册）：① 相同点集不同输入顺序 → 同 struct_hash/value_digest/hex；② 改一点 value → value_digest 变、struct_hash 不变；③ 改一点 name → struct_hash 变；④ 空集/边界（count=0）；⑤ 各类型有效字节稳定（bool/int32/int64/float/double/string，string 全 32B 固定）；⑥ 算法版本前缀存在。
   - `tests/unit/test_c_epoch.cpp`：① next 单调非零、current 正确；② stale check（旧 epoch 被拒、新的通过）；③ `advance_to` 推进；④ `epoch_key` 字典序（同 epoch 不同 node_id 可区分、不同 epoch 有序）。
   - RED→GREEN：先写测试（无实现 → 编译/链接失败 = RED，归档 RED 输出），实现后 GREEN。
4. **边界**：不新增 VSOA URL、不改 UDS opcode/POD/ABI/libindurtdb API、不接 peer connector、不填 B 段、不取证、不宣称集群同步具备；不改对外口径（已按 13 号 D1 修正）；不打 tag/合 main。digest 与 epoch 为纯地基，S2 才连接传输与会话。
