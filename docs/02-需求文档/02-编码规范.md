以下是为 **InduRTDB（Industrial Real-Time Database）** 项目量身定制的 **C 编码规范**，聚焦于**嵌入式、实时性、可靠性、可维护性**四大核心诉求，适用于 Linux/SylixOS 等工业边缘环境。

---

# **InduRTDB C 编码规范**
**版本：3.1.0** | 2026-08-09
**适用语言：C11 (-std=gnu11)**
**目标平台：Linux / SylixOS（ARM Cortex-A）**

> v3.0.0 纯 C11 重写。所有模块以 `irt_` 或 `indurtdb_` 前缀命名，零 C++ 依赖。

---

## 1. 总体原则

> **“确定性 > 抽象，可靠性 > 便利，简洁 > 智巧”**

- ✅ **零动态内存分配**：禁止 `malloc`/`free`，全部使用定长数组和栈分配；
- ✅ **零异常 / 零 RTTI**：C11 不涉及异常和 RTTI；
- ✅ **零系统调用阻塞**：所有 IPC 必须非阻塞或带超时；
- ✅ **确定性执行时间**：避免递归和复杂算法；
- ✅ **跨平台兼容**：不依赖 glibc 特有扩展，使用 `__atomic` builtins。

## 2. 语言特性

| 特性 | 说明 |
|------|------|
| **C11 (-std=gnu11)** | 库代码使用 C11 + GNU 扩展 |
| **原子操作** | 使用 `__atomic_*` GCC builtins，禁止 `stdatomic.h`（SylixOS 不完整支持） |
| **静态断言** | 使用 `IRT_STATIC_ASSERT` 宏验证布局（`_Static_assert` 的兼容包装） |
| **线程局部存储** | 使用 `_Thread_local`（`irt_api.c` 中 `g_last_error`） |
| **定长数组** | 替代动态内存，所有缓冲区编译期确定边界 |
| **C 风格字符串** | `char[n]` 替代 `std::string` |
| **函数指针** | 替代 `std::function` / lambda |
| **返回码** | `int` 返回 0=成功，非0=错误；`bool` 用于状态查询 |

> 📌 **禁止事项**：
> - 禁止 `malloc`/`free`/`new`/`delete`；
> - 禁止任何 C++ 头文件或 STL 容器；
> - 禁止虚函数、模板、异常；
> - 禁止 `printf`（使用项目日志宏）；

## 4. 内存与资源管理

### 4.1 共享内存
- 所有共享内存结构体必须为 **POD**，禁止包含指针；
- 使用 `IRT_STATIC_ASSERT` 验证大小与对齐：

```c
IRT_STATIC_ASSERT(sizeof(irt_header_t) == 64, "Header size mismatch");
IRT_STATIC_ASSERT(sizeof(indurtdb_point_t) == 128, "PointData layout changed");
```

### 4.2 资源管理
- 文件描述符在函数返回前显式关闭（无 RAII）；
- OSAL 层负责所有平台资源（shm/mmap）的分配/释放：

```c
void* irt_shm_os_map(const char* name, size_t size, bool* is_owner);
void  irt_shm_os_unmap(void* addr, size_t size, bool is_owner);
```

### 4.3 对齐要求
- 共享内存结构体必须显式对齐：

```c
typedef struct {
    // ...
} __attribute__((packed, aligned(128))) irt_point_t;
```

## 5. 并发与线程安全

### 5.1 原子操作
- 使用 `__atomic_*` GCC builtins（`__ATOMIC_ACQUIRE`/`__ATOMIC_RELEASE`/`__ATOMIC_RELAXED`）；
- 禁止使用 `stdatomic.h`（SylixOS 支持不完整）；
- Seqlock 序列号必须为 `uint64_t`，规避 ABA 问题。

### 5.2 锁策略
- **读路径无锁**（Seqlock 重试机制）；
- **写路径**：全局 Seqlock（`header->write_seq`），无内核锁；
- 禁止在 Seqlock 临界区内调用外部回调。

### 5.3 Seqlock 范式
```c
// 写者
uint64_t s0 = __atomic_load_n(&header->write_seq, __ATOMIC_ACQUIRE);
if (s0 & 1ULL) return IRT_ERR_BUSY;
__atomic_store_n(&header->write_seq, s0 + 1, __ATOMIC_RELEASE);
/* ... 写入点位数据 ... */
__atomic_store_n(&header->write_seq, s0 + 2, __ATOMIC_RELEASE);

// 读者 (peek)
uint64_t s0, s1;
do {
    s0 = __atomic_load_n(&header->write_seq, __ATOMIC_ACQUIRE);
    if (s0 & 1ULL) continue;
    /* ... 读取点位数据 ... */
    s1 = __atomic_load_n(&header->write_seq, __ATOMIC_ACQUIRE);
} while (s0 != s1);
```

## 6. 错误处理

### 6.1 返回码
- **全部使用 `int` 返回码**：0 = 成功，非 0 = 错误码；
- 错误详情通过 `_Thread_local` 变量 `g_last_error` 记录，通过 `indurtdb_get_last_error()` 查询。

```c
#define IRT_ERR_INVALID_ID  -1
#define IRT_ERR_NOT_INIT    -2
#define IRT_ERR_BUSY        -3
#define IRT_ERR_NOMEM       -4
```

### 6.2 日志规范
- 使用项目日志系统（`g_lwlog`），非 `printf`：

```c
LW_LOG_INFO("InduRTDB", "Point %u written successfully", id);
LW_LOG_ERROR("InduRTDB", "Invalid point ID: %u", id);
```

## 7. 文件与目录结构

### 7.1 头文件
- 公共 API：`include/indurtdb/indurtdb.h`（唯一公共头，26 个函数）；
- 内部头：`src/core/irt_*.h` 和 `src/internal/irt_*.h`（不安装）；
- OSAL 接口：`src/osal/irt_osal.h`。

### 7.2 源文件
- 每个 `.c` 文件 ≤ 500 行，单一职责；
- 模块边界：
  - `src/core/irt_shm.c` — 共享内存段管理
  - `src/core/irt_point_manager.c` — 点位读写
  - `src/core/irt_subscription.c` — 订阅/通知/心跳
  - `src/core/irt_config.c` — 配置解析
  - `src/api/indurtdb.c` — 公共 API 单例

### 7.3 注释
- Doxygen 风格，覆盖所有 public API；
- 关键算法必须注释原理（如 Seqlock 重试机制）：

```c
/**
 * @brief 写入 double 值到指定点位 (线程安全 / 多进程安全)
 * @param id  点位 ID (0 <= id < max_points)
 * @param value 待写入值
 * @return 0 成功，<0 错误码 (IRT_ERR_INVALID_ID / IRT_ERR_BUSY / IRT_ERR_NOT_INIT)
 * @note 使用全局 Seqlock 保护写入，读路径无锁
 */
int indurtdb_write_double(uint32_t id, double value);
```

## 8. 构建与编译

### 8.1 编译选项（GCC）
```bash
-std=gnu11 -Wall -Wextra -Werror \
-ffunction-sections -fdata-sections \
-D_GNU_SOURCE
```

### 8.2 链接
- 静态库 `libindurtdb.a`，由 CMake 构建；
- Linux 链接 `rt pthread`；SylixOS 无额外依赖；
- 平台通过 `CMAKE_SYSTEM_NAME` 自动选择 OSAL 实现。

### 8.3 依赖
- **零第三方运行时依赖**：ConfigLoader 为自研轻量 key=value 解析器；
- 测试依赖：Google Test（仅测试构建）。

## 10. 禁止事项清单（红线）

❌ 禁止以下行为，代码审查直接拒绝：
- 使用 `malloc`/`free` 或任何动态内存分配；
- 使用 `stdatomic.h`（用 `__atomic_*` builtins）；
- 在共享内存中存储指针；
- 使用 C++ 头文件或 STL；
- 使用 `printf`/`cout`（必须用项目日志宏 `g_lwlog`）；
- 无 `IRT_STATIC_ASSERT` 验证共享内存布局；
- 未处理的系统调用返回值（`shm_open`/`mmap` 等）。
