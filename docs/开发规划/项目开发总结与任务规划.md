### 1.2 v2.x 架构修正 (2026-05-11)

本次修正解决 v1.0 的致命问题：

| 问题 | v1.0 | v2.0 |
|------|------|------|
| Seqlock 粒度 | 每 Point 独立 Seqlock 对象 | 全局 `header_->write_seq` |
| PointManager 数据源 | 进程堆 `vector<unique_ptr<ISeqlock>>` | 共享内存 `PointData*` 数组 |
| peek() 实现 | `static temp` 拷贝 | `&points_[id]` 真零拷贝 |
| 编码规范遵循 | 全面违反 (STL/异常/虚函数) | 严格遵循 |
| 多进程共享 | 架构不支持 | 已验证 (6 个 fork 测试) |
| API 集成 | subscribe/loadConfig 是 stub | 完整实现 |

## 二、已完成的核心功能

### 2.1 Core 层

#### PointManager (非虚类)
- 直接操作共享内存 `PointData*` 数组
- 全局 Seqlock (`header_->write_seq`) 保护写入
- 模板 `write<T>` 编译期类型分发
- `peek()` 返回 `const PointData*` 共享内存指针（真零拷贝）
- `validate_id()`, `get_write_count()`, `get_timeout_count()`

#### SubscriptionManager (定长数组)
- `SubscriberSlot slots_[256]` 替代 `unordered_map`/`vector`
- C 风格函数指针 `SubscriptionCallback` 替代 `std::function`
- 共享内存心跳表 `SubscriberEntry*` 支持多进程
- `cleanup_zombies()` 清理超时订阅者

#### SharedMemorySegment
- `shm_open` + `ftruncate` + `mmap(MAP_SHARED)`
- Header 初始化 (magic/version/max_points/write_seq/stats)
- 创建者 (is_owner) 与使用者的权限区分
- `validate_header()` — magic + version 校验
- `shm_` 成员保持 OSAL 对象生命周期

#### Seqlock (轻量自由函数)
- `seqlock_write_begin(seq)` / `seqlock_write_end(seq, s0)`
- `seqlock_read(seq, points, id)` → `const PointData*`
- 零类层次，零异常，零堆分配
- inline 定义，编译期内联

#### ConfigLoader (轻量 YAML 解析器)
- 支持 SRS 定义的 YAML 格式
- `parse_point_config(path, result)` / `free_config_result(result)`
- 零第三方依赖

### 2.2 API 层

#### C++ API (InduRTDB 单例 + PIMPL)
- `initialize(instance_id, max_points, max_subscribers)`
- `write<T>(id, value)` + `write(id, const char*)` 非模板重载
- `read(id, out)` / `peek(id)` / `subscribe()` / `unsubscribe()`
- `load_config(path)` — YAML 解析 + 点位元数据初始化
- `update_heartbeat()` / `shutdown()`

#### C ABI (17 个函数)
- `indurtdb_initialize` / `indurtdb_shutdown`
- `indurtdb_write_bool/int32/double/string`
- `indurtdb_read_*` 系列
- `indurtdb_read_point` — 完整点位数据读取
- `indurtdb_get_last_error`

### 2.3 OSAL 层

- **统一 POSIX 实现**: 删除重复的 `linux/` wrapper 层
- **删除废弃 stubs**: 移除 `interface/` 下的旧 base 类
- **工厂模式**: `OSALFactory::create_shared_memory/time/threading/notification`
- **平台检测**: `INDURTDB_OS_LINUX` / `INDURTDB_OS_SYLIXOS`
