## 文档约定

- 文件夹名、文件名使用中文，并以数字前缀排序。
- 修改功能 / API / 架构时，必须同步更新对应文档，保持代码与文档一致（防止文档腐败）。
- **对外口径唯一来源**是 `01-白皮书/01-产品白皮书.md`。历史白皮书移入 `01-白皮书/归档/` 并标注"口径废弃"。
- 版本号在 `VERSION` 文件、CMake `project(VERSION)`、`indurtdb.h` 版本宏三处保持一致。修改版本时须同步更新三者。
- **发布（打 tag）前必须逐项勾选** [`06-开发规划/09-文档一致性检查清单.md`](./06-开发规划/09-文档一致性检查清单.md)。
- **变更卡**落 [`02-需求文档/changes/`](./02-需求文档/changes/)，**评审证据**落 [`03-设计文档/reviews/`](./03-设计文档/reviews/)，
  两者由 `scripts/check_change_card.py` / `check_review_evidence.py --require-second` 机械校验；
  合入与发版的统一出口是本地门禁 `bash scripts/check_all.sh`（见 `CODEBUDDY.md`《工程闸门与流程》）。
