# InduRTDB 文档总览

> 文档是 InduRTDB 唯一的对外接口。本目录按「由浅入深」的阅读顺序组织，文件夹与文件均以数字前缀排序。

## 目录结构

| 目录 | 内容 | 适合读者 |
|------|------|---------|
| [`01-白皮书/`](./01-白皮书/InduRTDB产品白皮书.md) | 产品白皮书：定位、用户体验、能力边界、场景 | 产品决策者、客户、初次了解者 |
| [`02-需求文档/`](./02-需求文档/) | 需求规格说明书（SRS）、编码规范 | 需求/架构/评审人员 |
| [`03-设计文档/`](./03-设计文档/) | 概要设计（HLD）、详细设计（LLD） | 架构师、开发者 |
| [`04-技术文档/`](./04-技术文档/Seqlock算法设计文档.md) | 专项技术深挖（Seqlock 无锁算法） | 进阶开发者 |
| [`05-SDK手册/`](./05-SDK手册/) | 快速入门、开发者指南、C / C++ API 参考 | 集成开发者 |
| [`06-开发规划/`](./06-开发规划/项目开发总结与任务规划.md) | 开发总结与任务规划 | 维护者、贡献者 |

## 推荐阅读路径

- **想了解产品** → `01-白皮书` → `05-SDK手册/01-快速入门指南`
- **要集成开发** → `05-SDK手册/01-快速入门指南` → `02-开发者指南` → `03/04 API 参考手册`
- **要理解架构** → `03-设计文档/01-概要设计文档` → `02-详细设计文档（LLD）` → `04-技术文档`
- **要贡献代码** → `02-需求文档/02-编码规范` → `06-开发规划`

## 文档约定

- 文件夹名、文件名使用中文，并以数字前缀排序（见仓库 `CLAUDE.md` 工作约定第 3 条）。
- 修改功能 / API / 架构时，必须同步更新对应文档，保持代码与文档一致（防止文档腐败）。
- 版本号以 `VERSION` 文件与 `CMakeLists.txt` 为准，当前 2.1.0。
