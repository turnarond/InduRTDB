## 一、交付范围与边界（先读此节）

**定位**：纯 C11 实现的工业实时数据库——边缘控制的**跨进程共享内存实时数据层**（数据链路中间热数据层），不是整条链路。

### 1.1 权威"做/不做"（以 README 为准）

| 做 | 不做（本产品边界外） |
|---|---|
| 跨进程共享内存实时点位存储（低延迟、确定性） | 南向设备接入（Modbus/OPC UA/S7 驱动） |
| 工业语义（quality / timestamp / unit / access） | 北向 SCADA 对接（OPC UA Server / MQTT） |
| 多进程读写、订阅、崩溃自愈 | 持久化 / 历史库 |
| 作为库被集成（find_package / pkg-config / FetchContent） | 主备切换 / 选主（全对等 active-active） |
| 集群 / 跨节点同步（v3.12 主特性，rtdbd 内自持、不依赖 node-server；13 号 D1，实施中） | — |

### 1.2 集群同步 / 主备 —— 边界（2026-11-25 按 13 号 D1 修正）

- **集群/跨节点同步：以 13 号 D1 为权威**——从"不做"移入本库边界，作为 v3.12 主特性；在 rtdbd 内做成独立服务、**不依赖 node-server**。此前"由 node-server 承担"的表述作废（与 13 号正式裁决冲突）。
- **当前实现状态**：`rtdbd` 已有 `SET_PEERS`/peers 表与 `sync_peer` 角色（集群**成员配置**与 NOTIFY 防回环）；真正的节点间数据同步（snapshot_epoch/digest/增量-全量/epoch 裁决）按 `docs/plans/2026-11-25-同步语义实施设计.md` 分 S1–S4 实施中，**尚未完成、不可宣称具备**。
- **主备切换/选主不做**：D2 裁决全对等 active-active（2..N 节点全量复制、所有节点可写、无主从），不做主备选举/故障切换。配置成员表（SET_PEERS/peers-file）≠ 配置主备关系。
- **node-server 直连 SHM 的写入不参与集群同步**（13 号 §8.3-1：直连 SHM 不经过 rtdbd、拿不到写权威与通知链）。

### 1.3 发布门与对外口径

- 发布门 **FAIL 7**（用户裁决保持、不手填假绿）：`ir_snapshot` 条目已在阶段一修复（现场 ctest-N 精确比对），当前仅 B 段 7 项 pending（P7/P8 已签实测项但字段不全，P3/P6/P9/P10/P11 不可得或未取证）。详见 §4.1。
- 对外平台口径维持"未验证、不支持生产部署"；SylixOS 单台板测通过（§2.2）**不等于** F2/F3a/F4 现场就绪，也不等于发布门放行。

## 二、能力达标清单

### 2.1 已有能力（v3.7–v3.11 基线）

- **存储与性能**：跨进程 shm 点位存储；x86 Release 实测 P99 0.04–1.4 μs（设计目标 ≤10 μs）；全类型读写 + 采集时刻 `_ts` + quality/unit/access。
- **点位生命周期**：CRUD + 元数据读写 + `find_by_name`；B4 delta 日志跨重启存活（默认关闭，`--delta-file` 启用）。
- **并发与韧性**：全局 Seqlock 无锁读；owner 崩溃接管、奇数 `write_seq` 恢复、fork 安全；v3.3 rtdbd 写权威（UDS 串行写 + UID 鉴权 + 审计 + 背压 + 优雅退出）。
- **扩容与批量**（v3.11）：10k 订阅、128 连接、批量读写（19/20）、CAPS（21）、SNAPSHOT_DONE（22）、动态订阅表、连接池与可观测统计。
- **可集成**：v2 句柄 API（`indurtdb_h_*`）+ v1 兼容 API（已标 deprecated）；find_package / pkg-config / FetchContent；公开 C API **117 个**（v1 62 / v2 55，由 `scripts/check_api_count.py` 锁定）。
- **可观测**：`RTDBD_OP_HEALTH`、SIGUSR1 dump、运行日志环形缓冲、审计环形缓冲。
