# InduRTDB 集成指南

> 面向把 InduRTDB 作为库引入自己 C/C++ 工程的开发者。三种方式任选其一。

## 前置：获取与安装

```bash
git clone https://github.com/turnarond/InduRTDB.git
cd InduRTDB && mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=<你的安装前缀> && make -j$(nproc)
cmake --install .
```

> **注意**：`indurtdb.pc` 内的 `prefix` 在 **configure 阶段**写入。请安装前缀务必在 configure 时通过 `-DCMAKE_INSTALL_PREFIX=<你的安装前缀>` 指定（如上所示），pkg-config 才能正确解析；仅用 `cmake --install --prefix` 而不设置 configure 前缀会导致 `.pc` 指向错误路径。

## 方式一：find_package（推荐，CMake 工程）

```cmake
find_package(InduRTDB REQUIRED)
target_link_libraries(app PRIVATE InduRTDB::indurtdb)
```
配置时指定安装前缀：`cmake .. -DCMAKE_PREFIX_PATH=<你的安装前缀>`。

## 方式二：pkg-config（非 CMake / Makefile 工程）

```make
CFLAGS += $(shell pkg-config --cflags indurtdb)
LDLIBS += $(shell pkg-config --libs indurtdb)
```
需 `export PKG_CONFIG_PATH=<你的安装前缀>/lib/pkgconfig`。

## 方式三：FetchContent / add_subdirectory（源码内嵌，无需安装）

```cmake
include(FetchContent)
FetchContent_Declare(indurtdb
    GIT_REPOSITORY https://github.com/turnarond/InduRTDB.git
    GIT_TAG main)
FetchContent_MakeAvailable(indurtdb)
target_link_libraries(app PRIVATE InduRTDB::indurtdb)
```
作为子项目引入时，InduRTDB 默认不构建自身 tests/examples、不安装，不污染你的工程。

## 版本检查

```c
#include <indurtdb/indurtdb.h>
/* INDURTDB_VERSION_STRING == "3.1.0" */
```

## 最小示例

```c
#include <indurtdb/indurtdb.h>
int main(void){
    indurtdb_initialize("my_app", 1024, 8);
    indurtdb_write_double(1, 25.5);
    double t; indurtdb_read_double(1, &t);
    indurtdb_shutdown();
    return 0;
}
```
